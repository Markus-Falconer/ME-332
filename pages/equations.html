Basics (from the class sheet)

Convection, radiation, resistances
$$q = hA(T_s - T_\infty),\qquad q = \varepsilon\sigma A(T_s^4 - T_{sur}^4) = h_rA(T_s - T_{sur}),\qquad h_r = \varepsilon\sigma(T_s + T_{sur})(T_s^2 + T_{sur}^2)$$ $$R_{conv} = \frac{1}{hA},\quad R_{plane} = \frac{L}{kA},\quad R_{cyl} = \frac{\ln(r_o/r_i)}{2\pi kL},\quad q = \frac{T_H - T_C}{\sum R},\quad \sigma = 5.67\times10^{-8}\ \text{W/m}^2\text{K}^4$$
Lumped capacitance ($Bi = hL_c/k \lt 0.1$, $L_c = V/A_s$)
$$\frac{T - T_\infty}{T_i - T_\infty} = \exp\left(-\frac{hA_s}{\rho Vc}t\right),\qquad \tau = \frac{\rho Vc}{hA_s},\qquad \rho Vc\frac{dT}{dt} = q_s''A_{s,h} + \dot E_g - hA_s(T - T_\infty) - \varepsilon\sigma A_s(T^4 - T_{sur}^4)$$

Ch 7: External Flow

Flat plate (properties at $T_f$, $Re_{x,c} = 5\times10^5$)
$$\text{Lam: } Nu_x = 0.332Re_x^{1/2}Pr^{1/3},\ \ \overline{Nu}_L = 0.664Re_L^{1/2}Pr^{1/3},\ \ \delta = 5xRe_x^{-1/2},\ \ \delta/\delta_t \approx Pr^{1/3}$$ $$\text{Turb: } Nu_x = 0.0296Re_x^{4/5}Pr^{1/3},\ \ \overline{Nu}_L = 0.037Re_L^{4/5}Pr^{1/3}\qquad \text{Mixed: } \overline{Nu}_L = (0.037Re_L^{4/5} - 871)Pr^{1/3}$$ $$\text{Uniform } q_s'': Nu_x = 0.453Re_x^{1/2}Pr^{1/3}\ (\text{lam}),\ \ 0.0308Re_x^{4/5}Pr^{1/3}\ (\text{turb})$$
Unheated starting length
$$Nu_x = \frac{Nu_x|_{\xi=0}}{[1 - (\xi/x)^{3/4}]^{1/3}}\ (\text{lam}),\qquad Nu_x = \frac{Nu_x|_{\xi=0}}{[1 - (\xi/x)^{9/10}]^{1/9}}\ (\text{turb})$$ $$\overline{Nu}_L = \overline{Nu}_L|_{\xi=0}\frac{L}{L - \xi}[1 - (\xi/L)^{(p+1)/(p+2)}]^{p/(p+1)},\quad p = 2\ (\text{lam}),\ 8\ (\text{turb}),\quad q = \bar h(L - \xi)W\Delta T$$
Cylinder and sphere
$$\overline{Nu}_D = 0.3 + \frac{0.62Re_D^{1/2}Pr^{1/3}}{[1 + (0.4/Pr)^{2/3}]^{1/4}}\left[1 + \left(\frac{Re_D}{282{,}000}\right)^{5/8}\right]^{4/5}\qquad \overline{Nu}_D = CRe_D^mPr^{1/3}\ (\text{Hilpert})$$ $$\overline{Nu}_D = 2 + (0.4Re_D^{1/2} + 0.06Re_D^{2/3})Pr^{0.4}(\mu/\mu_s)^{1/4}\ (\text{sphere})$$

Ch 8: Internal Flow

Flow and entry lengths
$$Re_D = \frac{4\dot m}{\pi D\mu}\ (\text{lam} \lt 2300),\quad x_{fd,h} \approx 0.05Re_DD,\quad x_{fd,t} \approx 0.05Re_DPr\,D,\quad \text{turb: } \approx 10D,\quad D_h = \frac{4A_c}{P}$$
Energy balance and surface conditions
$$q = \dot mc_p(T_{m,o} - T_{m,i})\qquad \text{uniform } q_s'': T_m(x) = T_{m,i} + \frac{q_s''P}{\dot mc_p}x,\ \ T_s = T_m + \frac{q_s''}{h}$$ $$\text{uniform } T_s: \frac{T_s - T_{m,o}}{T_s - T_{m,i}} = e^{-\bar hPL/\dot mc_p},\ \ q = \bar hA_s\Delta T_{lm}\qquad \text{external fluid: } \frac{T_\infty - T_{m,o}}{T_\infty - T_{m,i}} = e^{-\bar UA_s/\dot mc_p}$$
Correlations
$$Nu_D = 4.36\ (q''),\ \ 3.66\ (T_s)\qquad \overline{Nu}_D = 3.66 + \frac{0.0668Gz_D}{1 + 0.04Gz_D^{2/3}},\ \ Gz_D = \frac{D}{L}Re_DPr$$ $$Nu_D = 0.023Re_D^{4/5}Pr^n\qquad Nu_D = \frac{(f/8)(Re_D - 1000)Pr}{1 + 12.7(f/8)^{1/2}(Pr^{2/3} - 1)},\ \ f = (0.790\ln Re_D - 1.64)^{-2}$$

Ch 11: Heat Exchangers

$U$, energy balance, LMTD
$$\frac{1}{UA} = \frac{1}{(hA)_c} + \frac{R''_{f,c}}{A_c} + R_w + \frac{R''_{f,h}}{A_h} + \frac{1}{(hA)_h},\qquad q = C_h(T_{h,i} - T_{h,o}) = C_c(T_{c,o} - T_{c,i})$$ $$q = UAF\Delta T_{lm},\quad \Delta T_{lm} = \frac{\Delta T_2 - \Delta T_1}{\ln(\Delta T_2/\Delta T_1)},\quad \text{CF: } \Delta T_1 = T_{h,i} - T_{c,o},\ \Delta T_2 = T_{h,o} - T_{c,i};\ \ \text{PF: inlets/outlets}$$
ε–NTU
$$\varepsilon = \frac{q}{C_{min}(T_{h,i} - T_{c,i})},\quad NTU = \frac{UA}{C_{min}},\quad C_r = \frac{C_{min}}{C_{max}}$$ $$\text{PF: } \varepsilon = \frac{1 - e^{-NTU(1 + C_r)}}{1 + C_r}\qquad \text{CF: } \varepsilon = \frac{1 - e^{-NTU(1 - C_r)}}{1 - C_re^{-NTU(1 - C_r)}}\ \ (C_r = 1: \tfrac{NTU}{1 + NTU})\qquad C_r = 0: \varepsilon = 1 - e^{-NTU}$$ $$\text{Cross, both unmixed: } \varepsilon = 1 - \exp\left[\frac{NTU^{0.22}}{C_r}(e^{-C_rNTU^{0.78}} - 1)\right]$$ $$\text{1 shell pass: } NTU = -(1 + C_r^2)^{-1/2}\ln\frac{E - 1}{E + 1},\ \ E = \frac{2/\varepsilon - (1 + C_r)}{(1 + C_r^2)^{1/2}}\qquad \text{CF: } NTU = \frac{1}{C_r - 1}\ln\frac{\varepsilon - 1}{\varepsilon C_r - 1}$$
